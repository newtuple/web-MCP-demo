# Blog content

Create one Markdown file per post. Required frontmatter keys:

- title
- description
- date
- slug

Optional:
- updated
- author
- tags
- heroImage
- canonical
- comments (set to false to disable)

Example:

---
title: "Example post"
description: "Short summary for SEO."
date: "2025-12-15"
updated: "2025-12-20"
author: "Newtuple"
slug: "example-post"
tags: ["agents", "systems"]
heroImage: "/blog/example-hero.jpg"
comments: true
---
