# Agent Domain Images

Place your agent domain artwork/images here. The expected filenames are:

- `pmo.jpeg` or `pmo.jpg` - PMO domain image
- `recruitment.jpeg` or `recruitment.jpg` - Recruitment domain image
- `data-engineering.jpeg` or `data-engineering.jpg` - Data Engineering & Analytics domain image
- `sales-ops.jpeg` or `sales-ops.jpg` - Sales Ops / GTM Agents domain image
- `customer-support.jpeg` or `customer-support.jpg` - Customer Support / CX domain image
- `finance-billing.jpeg` or `finance-billing.jpg` - Finance & Billing domain image

Supported formats: JPEG, JPG, PNG, SVG

Note: Current files use .jpeg/.jpg format. The code will automatically use these extensions.
