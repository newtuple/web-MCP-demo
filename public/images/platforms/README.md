# Platform Icons

Place your platform icon images here. The expected filenames are:

- `dialogtuple.png` or `dialogtuple.svg` - Dialogtuple logo
- `microsoft-copilot-studio.png` or `microsoft-copilot-studio.svg` - Microsoft Copilot Studio logo
- `n8n.png` or `n8n.svg` - n8n logo
- `langraph.png` or `langraph.svg` - Langraph logo

Supported formats: PNG, SVG, JPG
